# tictaktoe
A C++ implementation of a modified 6×7 Tic-Tac-Toe game, created during my summer break to practice and strengthen my C++ programming skills.

#Features
Player vs Player
Player vs Computer
Computer moves using rand()
6×7 game board
Custom game rules

#Concepts Used

Object-Oriented Programming
Arrays
Functions
Random Number Generation
Game Logic
